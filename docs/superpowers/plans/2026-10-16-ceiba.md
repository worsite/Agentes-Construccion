# Ceiba Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar `ceiba/index.html` (landing con precios mensual/anual y tres paquetes por ciclo) y `ceiba/app.html` (app de notas en markdown), verificados con pruebas ejecutadas.

**Architecture:** Dos páginas HTML autocontenidas (CSS y JS en línea), sin build ni dependencias externas. En `app.html` el JS se organiza en un espacio de nombres puro `window.Ceiba` (funciones sin estado, probables en aislamiento) y una capa de aplicación (estado, almacenamiento, interfaz, teclado). Pruebas con Playwright sobre un servidor estático local.

**Tech Stack:** HTML5, CSS custom properties, JavaScript ES2020 vanilla, Playwright 1.56 (global) con Chromium en `/opt/pw-browsers`, Node 22.

**Spec:** `docs/superpowers/specs/2026-10-16-ceiba-design.md`

## Global Constraints

- Sin emojis ni pictogramas decorativos en ningún archivo (regex `\p{Extended_Pictographic}` y U+FE0F deben dar 0 coincidencias).
- Sin recursos externos: ninguna petición de red; fuentes del sistema; CSP por `<meta>` según la spec sección 2.
- Tokens de color de la spec sección 3, claro y oscuro; pares texto/fondo >= 4.5:1.
- Marcador de demostración visible: "Demostración: los planes y precios son ficticios y no se realiza ningún cobro."
- Planes: Semilla 5/50, Brote 9/90, Bosque 18/180 US$ (mes/año). Equivalentes mensuales anuales 4,17 / 7,50 / 15,00; ahorros 10 / 18 / 36.
- Claves de `localStorage`: `ceiba:notas:v1`, `ceiba:prefs:v1`.
- Atajos con `event.code`: `Alt+KeyN` nueva, `Alt+Backspace` eliminar, `Alt+KeyP` vista previa, `Alt+Backslash` enfoque, `Ctrl/Cmd+KeyK` o `Slash` buscar, `Shift+Slash` ayuda.
- Español neutro, `lang="es"`. Idioma de commits: español.
- Lo que no existe se declara "en preparación"; nada se presenta como disponible si no lo está.

## Review Focus

- Markdown hostil (HTML crudo, `javascript:` camuflado, 1 MB de `*` o `[`): no ejecuta nada, no se cuelga (< 2 s).
- `localStorage` bloqueado, lleno o con JSON roto: no hay pantalla en blanco y no se pisan los datos rotos.
- Dos pestañas editando: la segunda avisa y no sobrescribe en silencio.
- Eliminar la última nota, buscar sin resultados, nota de 200 KB, título de 5.000 caracteres: la interfaz se mantiene usable.
- Reloj del sistema modificado, cambio de zona horaria, fechas futuras: tiempos relativos coherentes (nunca "hace -3 min").

### Task 1: Núcleo puro `window.Ceiba` en `ceiba/app.html`

**Files:** Create `ceiba/app.html` (solo `<head>`, CSP, y `<script>` con `window.Ceiba`), `ceiba/tests/unit.mjs`.

**Interfaces — Produces** (todas puras, síncronas):
- `Ceiba.escapar(s: string): string`
- `Ceiba.titulo(texto: string): string` (primera línea no vacía sin `#`, máx. 80, "Sin título")
- `Ceiba.extracto(texto: string): string` (primera línea con texto tras el título, máx. 120)
- `Ceiba.normalizar(s: string): string` (NFD sin marcas, minúsculas)
- `Ceiba.coincide(nota: {texto}, consulta: string): boolean` (todas las palabras)
- `Ceiba.tiempoRelativo(ms: number, ahora: number, loc?: string): string`
- `Ceiba.fechaCompleta(ms: number, loc?: string): string`
- `Ceiba.renderMarkdown(texto: string): HTMLElement` (devuelve un `DocumentFragment` o `div`; nunca `innerHTML` con texto sin escapar)
- `Ceiba.urlSegura(url: string): string | null`
- `Ceiba.validarImportacion(json: unknown): { notas: Nota[], omitidas: number } | { error: string }`
- `Ceiba.nombreArchivo(titulo: string): string`

- [ ] Escribir `unit.mjs` con casos de cada función (valores de la spec: esquemas de URL, XSS, tablas, listas anidadas, bloques sin cerrar, 1 MB hostil < 2 s, 200 KB < 300 ms) y ejecutar: debe FALLAR.
- [ ] Implementar cada función con las firmas de arriba hasta que pase.
